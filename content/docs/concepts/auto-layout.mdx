# Auto layout

Auto layout arranges a container's children using direction, spacing, padding, alignment, and sizing rules. Use it for repeated items, buttons, cards, and sections that need to respond when their contents change. The inspector separates a container's layout settings from each selected child's sizing and alignment settings.

## Set up a layout

1. Select a frame or another supported container.
2. Open the **Layout** section in the inspector and enable auto layout.
3. Choose the direction, spacing, padding, and alignment.
4. Select a child to adjust its sizing or placement within the layout.
5. Resize the container or edit child content to check the result.

You can also reach layout actions from the layer context menu. A free-positioned layer may move when you put it into a layout container because the parent now calculates child placement. Check the result on the canvas.

The canvas supports an 8 px snap grid and nearby node edges and centers while moving objects; snapping is a separate feature from auto layout. Inspector layout controls live in `crates/fig_viewer/src/properties_panel.rs`, and layer actions in `crates/fig_viewer/src/layer_context_ops.rs`.
