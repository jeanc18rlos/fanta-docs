# Document model

A Fanta design is a local project folder. New Design creates a project with a page. The folder contains `fanta.json`, `pages/<slug>/page.fnx`, `components/<slug>/master.fnx`, document metadata under `doc/`, and assets under `assets/`. The FNX files describe the editable layer trees; sidecar files preserve details such as identity and ordering. Generated previews and exports are ignored by Git.

A page has a root and its own layer tree. Frames, shapes, text, images, paths, groups, sections, slices, component instances, and other node kinds live in that tree. Properties include geometry, paints, typography, effects, layout, variable bindings, and prototype interactions. The editor exposes those properties through the canvas and inspector according to the selected node.

## Work with a project

1. Choose **File → New Design** or open a supported design.
2. Add and organize pages in the Layers panel.
3. Edit layers on the canvas or in the inspector. Fanta saves local changes after a short delay.
4. Switch to the Code workspace when you need to inspect or edit FNX. Save valid source to update the canvas.
5. Use **File → Review Changes** or **Commit** when you want to inspect or record project changes in Git.

Opening a bare `.fig` file creates an editable sibling Fanta project and leaves the original file untouched. `.fig` is an import format, not Fanta's native save target. Fanta can also import `.fant` files. Export from the inspector to PNG, JPG, SVG, or PDF; export is separate from saving the project.

Fanta watches project files for external edits. If the canvas has no unsaved changes, an external edit can reload. With local edits, Fanta attempts a three-way merge and surfaces conflicts for review. Keep the project folder together when sharing or moving it.

## Source references

The folder layout is defined in `crates/fanta-format/src/project/layout.rs` and `crates/fanta-format/src/project/project.rs`. New Design and import behavior are in `crates/fig_viewer/src/new_design.rs` and `crates/fig_viewer/src/document.rs`. Source saving is in `crates/fanta-format/src/project/source_edit.rs`.
