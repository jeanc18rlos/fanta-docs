# Pages and coordinates

A project can contain multiple pages. Use the Pages section of the Layers panel to create, select, rename, duplicate, reorder, or delete pages. A page contains its own layer tree, and selecting it changes the active canvas. The panel can also search and replace names and text.

Canvas coordinates use pixels with X increasing to the right and Y increasing downward. Canvas and live design tool coordinates are in world space. A node's visible position combines its parent transforms. In FNX, placement is represented relative to its parent, so a child may have different local and canvas coordinates.

## Place and inspect a layer

1. Select the intended page.
2. Create a frame or shape with a toolbar tool, or use a live design tool.
3. Select the layer and use the inspector's X, Y, width, height, and rotation controls for precise changes.
4. Use the Layers panel to move a layer within or between page trees.

A page root scopes rendering and export. When exporting the active page, unrelated pages do not appear just because they reuse the same coordinate values. You can also export selected layers.

The page operations are implemented in `crates/fig_viewer/src/design_panel.rs` and `crates/fig_viewer/src/gpui_adapters/pages.rs`. Export targeting is in `crates/fig_viewer/src/export.rs`.
