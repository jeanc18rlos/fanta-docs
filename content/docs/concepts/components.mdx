# Components and instances

A component is a reusable master layer tree. An instance refers to that master and can carry local overrides. Fanta stores component masters in `components/<slug>/master.fnx`, alongside the project's page source.

## Create and use a component

1. Put the layers you want to reuse in a frame or group, then select that container.
2. Use the component action in the layer context menu or inspector.
3. Add an instance from the available component controls.
4. Select the instance to change supported local properties.
5. Use the instance controls to reset overrides or detach the instance when you need an independent layer tree.

Components can have variants. Variant and instance controls appear in the inspector when relevant. If an instance differs unexpectedly from its master, inspect its overrides before resetting it; reset intentionally discards those local changes.

Component and instance operations are implemented in `crates/fig_viewer/src/properties_ops.rs` and the layer context actions. Storage is defined in `crates/fanta-format/src/project/layout.rs`.
