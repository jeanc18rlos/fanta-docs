Fantaisa is a Cargo workspace; you run each piece with `cargo run -p <crate>`.
This page lists the binaries and the environment variables that configure them.

## Binaries

| Command | What it runs |
| --- | --- |
| `cargo run -p fanta-app` | The desktop editor. Auto-starts the live MCP server on `127.0.0.1:3846`. |
| `cargo run -p fanta-ai --bin fanta-mcp` | The headless MCP server: stdio JSON-RPC over an in-memory document. |
| `cargo run -p fanta-ai --bin fanta-mcp -- --live` | A stdio→HTTP proxy from a stdio MCP client to the running editor. |
| `cargo run -p fanta-fidelity` | The fidelity render/diff CLI for fidelity corpora. |

<Tabs items={['Desktop editor', 'Headless MCP', 'Live proxy']}>

<Tab value="Desktop editor">

```bash title="Launch the editor (hosts the live MCP on :3846)"
cargo run -p fanta-app
```

The visible canvas is reachable over Streamable HTTP at
`http://127.0.0.1:3846/mcp`. This is the preferred surface for driving the live
editor.

</Tab>

<Tab value="Headless MCP">

```bash title="Headless, in-memory document — good for CI and batch generation"
cargo run -p fanta-ai --bin fanta-mcp
```

`fanta-mcp` owns its own in-memory document with no UI and speaks JSON-RPC over
stdio. Keep stdout pure JSON-RPC — logs go to stderr.

</Tab>

<Tab value="Live proxy">

```bash title="Proxy a stdio MCP client to the visible editor"
cargo run -p fanta-ai --bin fanta-mcp -- --live
```

Use this when your MCP client only speaks stdio but you want it to drive the
running desktop editor at `127.0.0.1:3846`.

</Tab>

</Tabs>

<Callout type="info">
  Streamable-HTTP clients should connect directly to `http://127.0.0.1:3846/mcp`
  against a running editor — no separate server needed. Use `fanta-mcp --live`
  only for stdio-only clients.
</Callout>

## Environment variables

| Variable | Purpose |
| --- | --- |
| `ANTHROPIC_API_KEY` | API key for the Anthropic client used by `fanta-ai`. |
| `FANTA_AI_MODEL` | Override the model the AI surface uses. |
| `FANTA_LLM_BASE_URL` | Point the LLM client at an alternate, compatible endpoint. |
| `FANTA_MCP_ADDR` | Override the live MCP bind address (default `127.0.0.1:3846`). |
| `RUST_LOG` | Standard Rust log filter (logs go to stderr). |

```bash title="Example: run the editor on a different MCP port with debug logs"
FANTA_MCP_ADDR=127.0.0.1:4000 RUST_LOG=debug cargo run -p fanta-app
```

```bash title="Example: headless MCP against a custom model"
ANTHROPIC_API_KEY=sk-... FANTA_AI_MODEL=claude-... cargo run -p fanta-ai --bin fanta-mcp
```
