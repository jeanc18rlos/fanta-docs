## October 11, 2026 source update

The docs now track published `fanta-edit` main at [`22f73419`](https://github.com/jeanc18rlos/fanta-edit/tree/22f734193844eab66485e3cb322b529c2965e297). On direct-download macOS, a fresh `.fig` import stages and flushes a complete sibling project before publishing it; if publication fails, the parsed design remains open for a save retry. The project guide also clarifies received-folder Restricted Mode and the limits of concurrent external writes.

Canvas snapping now searches indexed layer targets in the active page or opened component subtree. A Select gesture cancels its pending move if the mouse press is lost, and editable Design Crop shows Ratio, Cancel, and Apply controls. Billing usage charts use one rolling UTC window for their 7, 30, or 90-day daily and key views. Project loading and text-layout caching changed internally; these source changes and mounted tests do not establish native responsiveness or complete installed-app acceptance.

Maintainers can opt into macOS release build diagnostics. The latest documented internal arm64 DMG check used earlier source `79cc2ef8` and an ad-hoc signature; its public release job was skipped. A Developer ID-signed, notarized download and clean-Mac installation remain unverified. The local canvas MCP interface remains 13 tools and 43 design operations.

## October 9, 2026 source update

The docs now track published `fanta-edit` main at [`79cc2ef8`](https://github.com/jeanc18rlos/fanta-edit/tree/79cc2ef8c094149e8496476c1cb53e2945b8b54a). A single editable TextPath layer offers **Edit object** in the inspector, and **Select matching layers** treats Sections as Sections on the active page. The canvas Properties menu also routes supported specialist layers to the Design inspector. These paths have mounted editor tests; installed-app acceptance remains separate.

JPEG export now uses fixed quality 95, remains lossy, and writes an opaque image. A focused bitmap regression passes, while the source coverage report still records an earlier native JPEG comparison failure. The renderer now retains unaffected effect layers during scene edits and invalidates affected layers; native responsiveness is still under validation.

For outbound account-backed MCP, a failed startup now preserves an unused endpoint OAuth session. Local canvas MCP remains 13 tools and 43 design operations. The release coverage report records bounded Audio and internal ad-hoc DMG checks, but cold MP3 preview was absent in its placement fixture. A Developer ID-signed public download, clean-Mac install, and live managed-service journeys remain unverified.

## October 8, 2026 source update

The docs now track published `fanta-edit` main at [`d386b9f4`](https://github.com/jeanc18rlos/fanta-edit/tree/d386b9f48557c35302ae8b28c195db453f490141). FNX printing now preserves finite numeric values exactly, including very small values that previously printed as zero. The media guides clarify placement routes: the local picker handles supported raster images and MP4 video; editable SVG can come from Project Assets or generation results, while audio placement uses Project Assets. Video preview and trim have bounded development checks, while arbitrary codecs and installed-release media behavior remain unverified.

The Mac packaging workflow now aligns both bundle version fields with the source version and retries the specific transient busy-disk-image error without replacing a prior finished DMG. These checks improve packaging reliability; the signed download and clean-Mac installation remain separate release gates. The external MCP interface remains at 13 tools and 43 design operations.

## October 7, 2026 source update

The docs now track published `fanta-edit` main at [`a022ddb4`](https://github.com/jeanc18rlos/fanta-edit/tree/a022ddb4eb0828dea734584aea8e63e6cb503c05). Structural canvas saves preserve authored FNX attributes and comments on surviving nodes; Save reports a preservation error if a destructive edit would lose source-only data. During an unsaved source draft, the accepted properties of one selected layer remain readable while canvas writing stays locked.

Canvas Cut, Delete, and Duplicate now respect layer locks more consistently. Paste checks component dependencies and can restore a captured component or complete variant set after its original definition was removed. The inspector shows more resolved variable values and independent corner fields; variant navigation and instance text editing follow the visible member and binding rules. Edit Path shows anchors on entry, and Escape can finish active canvas text editing. The external MCP roster remains 13 tools with 43 design operations.

The retained Metal translation renderer is opt-in and its native performance target remains unverified. The selected distribution is a direct-download Mac app, with mounted-DMG verification added to packaging; signed download and clean-Mac installation still require validation. The [release coverage report](https://github.com/jeanc18rlos/fanta-edit/blob/a022ddb4eb0828dea734584aea8e63e6cb503c05/docs/alpha/CAPABILITY_COVERAGE.md) distinguishes bounded checks from release readiness.

## October 6, 2026 source update

The docs now track published `fanta-edit` main at [`8fe28c69`](https://github.com/jeanc18rlos/fanta-edit/tree/8fe28c69bda2dca80bd01c70f93a6912148e7668). Figma import now preserves supported Boolean operands and warns about known flattened or omitted structures. Canvas and keyboard duplication preserve copied component definitions, complete variant sets, and supported internal prototype links; same-document Paste retains existing definitions, while cross-document canvas Paste reports that it is unsupported. The inspector adds or repairs controls for mixed selections, bound paint, Boolean nodes, rotation, flipping, alignment, distribution, and Tidy up.

The Code workspace gains embedded Find, selected-buffer **Discard draft**, and source Save/Undo preservation. The editor also improves project/source reload ownership and layout preservation. The prototype detail's **X** closes the detail without deleting its interaction; **Remove** is the deletion action. Current time in Motion accepts a typed seek. The [source release coverage report](https://github.com/jeanc18rlos/fanta-edit/blob/8fe28c69bda2dca80bd01c70f93a6912148e7668/docs/alpha/CAPABILITY_COVERAGE.md) records bounded native checks alongside open large-project Save, draft recovery, final artifact, and distribution gates. These implementation changes do not establish a new packaged release.

## October 5, 2026 source update

The docs now track published `fanta-edit` main at [`23b1ff95`](https://github.com/jeanc18rlos/fanta-edit/tree/23b1ff95766052a83351e6584171b58a21f7f570). The external server still exposes 13 MCP tools, with 43 `batch_design` operations. These pages describe merged implementation; packaged release and hosted-service availability require separate verification.

## October 4, 2026 source update

The docs now track published `fanta-edit` main at [`af712551`](https://github.com/jeanc18rlos/fanta-edit/tree/af712551269bdd2c7eedc45d0ea1567228fae686). The Code workspace can edit the active page or component's paired JSON alongside FNX, validate the complete candidate against the project, and reload the canvas. Modern FNX with explicit IDs can recover a missing or damaged sidecar. A failed external source reload keeps the last valid canvas and reports a repairable error.

External `batch_design` still exposes 33 operations through the same 13 MCP tools, but now streams each operation visibly while retaining one undoable, rollback-safe batch. An optional `activity` identity and richer `report_agent_activity` fields let Fanta follow an agent across the Canvas, Variables, and Code workspaces. The source also improves property editing, component-master navigation, and the in-app agent workflow. These are implementation claims, not a new packaged release announcement.

## Current alpha documentation

This edition introduced the Zed-derived Fanta app and its `.fnx` project workflow. It corrected earlier references to a separate `fanta-app` executable, fixed HTTP MCP port, and per-action MCP roster. At that source revision the external interface had six tools through `fanta --mcp-stdio`; the October 3 source revision above extends it to 13.

The docs cover project creation, Git review, Figma import, the agent build loop, source editing, and the supported alpha editor paths. The [source](https://github.com/jeanc18rlos/fanta-edit) and its [known issues](https://github.com/jeanc18rlos/fanta-edit/blob/main/docs/alpha/KNOWN_ISSUES.md) remain the record of implementation and validation status.

At that revision, several visible controls were not connected. The dated entries above supersede those observations where implementation changed. The issue log and release coverage report separate current source behavior from native-app and distribution validation.
