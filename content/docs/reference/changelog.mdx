## September 29, 2026 source update

The docs now track `fanta-edit` main at [`ebabb405`](https://github.com/jeanc18rlos/fanta-edit/tree/ebabb405779ef9772b8b2de6f227ad5a9776bdc6). Its implemented changes include a persistent Project Assets panel; placement of generated image, SVG, MP4, and WAV/MP3/FLAC audio assets; audio preview, duration, seeking, and save fixes; catalog-driven generation controls; managed chat-model discovery; the in-app Jev evaluation tool; and a new Settings window with MCP, account, billing, and privacy sections.

The source also contains a Mac App Store feature build with process and Git restrictions. The distribution and packaged external-agent bridge are described conditionally because source and merged commits alone do not establish public availability or end-to-end release validation.

## Current alpha documentation

This edition describes the Zed-derived Fanta app and its `.fnx` project workflow. It corrects earlier references to a separate `fanta-app` executable, fixed HTTP MCP port, and per-action MCP roster. The current external interface has six tools through `fanta --mcp-stdio`.

The docs cover project creation, Git review, Figma import, the agent build loop, source editing, and the supported alpha editor paths. The [source](https://github.com/jeanc18rlos/fanta-edit) and its [known issues](https://github.com/jeanc18rlos/fanta-edit/blob/main/docs/alpha/KNOWN_ISSUES.md) remain the record of implementation and validation status.

Some visible controls are not connected. Grid auto-layout, several blend/effect modes, and some toolbar actions are examples. The known issues separate observed release behavior from source-only or unit-tested paths.
