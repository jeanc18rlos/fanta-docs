---
title: Version-control your designs
description: Review the source diff behind each canvas change.
---

Fanta writes canvas edits to the design project after a short autosave delay. The folder is initialized as a Git repository when Git is available, except when already inside another repository. A `.fig` import creates a source-backed project beside the original file; commit the project, not the import alone.

1. Make a canvas or `.fnx` edit.
2. Inspect a screenshot of the changed frame or page.
3. Choose **File → Review Changes** or run `git diff` in the project. Confirm the source diff matches the intended visual result.
4. Commit through **File → Commit…** or your Git client, including any new assets the design uses.

The external MCP server edits the design but does not commit it. The old `vcs_*` tool names are absent. If no `.git` was created because system Git was unavailable, install Xcode Command Line Tools or initialize the repository yourself.
