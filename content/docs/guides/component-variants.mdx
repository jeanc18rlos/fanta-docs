---
title: Build a component & variants
description: Create a reusable master and place a linked instance.
---

1. Build a frame or group for the reusable element and inspect its exact ID with `batch_get`.
2. Promote it with `{"op":"create_component","id":"<frame-id>"}` in `batch_design`. The master stays on canvas, and the response includes its component ID.
3. Place a linked copy with `create_instance`, passing that ID and world `x`/`y` coordinates. A unique name also works, but an ID avoids ambiguity.
4. Change the master, screenshot an instance, and inspect the component source under `components/`.

```json
{"label":"Place button","ops":[{"op":"create_instance","component":"<component-id>","x":480,"y":120}]}
```

Master and instance operations are in the external MCP schema. Variant-set creation and per-instance overrides are not dedicated MCP ops in this alpha. Inspect the editor UI and `.fnx` representation before using those paths.
