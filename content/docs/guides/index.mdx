variant set, running a swarm, or wiring designs into git. They assume you have a
live editor and have read [the build loop](/docs/mcp/build-loop).

## Before you start

Every guide assumes the same front matter, in this order:

1. [`agent_playbook`](/docs/mcp/build-loop) — load the rules of the house.
2. [`get_guidelines`](/docs/mcp/build-loop) — pull the right guide and style.
3. Inspect (`get_editor_state` / `get_document` / `snapshot_layout`).

Then follow the guide's steps. See the [tool reference](/docs/tools) for the full
catalog and [Get the best output](/docs/mcp/best-output) for the hard rules each
step depends on.
