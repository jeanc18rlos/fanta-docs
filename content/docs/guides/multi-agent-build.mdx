---
title: Run a multi-agent build
description: Coordinate agents without assuming a Fanta task-lock system.
---

The external MCP server acts on the most recently focused design. `batch_design` is atomic and undoable, but it does not lock nodes across agents. Assign one coordinator to review combined work.

1. Map pages and components with `get_editor_state` and `batch_get`.
2. Give each agent a distinct page, frame, component, or `.fnx` file. Share exact IDs or paths.
3. Have each agent finish canvas edits and let autosave complete before another edits the same source file. Do not mix canvas and source edits on the same nodes simultaneously.
4. Verify each region with `get_screenshot` and inspect the Git diff for unexpected changes.
5. Commit reviewed changes with ordinary Git.

Fanta’s six-tool external MCP surface has no `spawn_agent`, `vcs_begin_task`, cursor presence, or cross-agent locks. Parallel coordination belongs to the client or team workflow.
