# Keyboard shortcuts

These are the default macOS canvas bindings. A tool can use a shortcut while the canvas has focus; a text field may consume the same key for typing.

| Action | Shortcut |
| --- | --- |
| New Design | Command N |
| Undo / Redo | Command Z / Command Shift Z |
| Copy / Cut / Paste | Command C / Command X / Command V |
| Duplicate | Command D |
| Delete | Delete |
| Select all | Command A |
| Group / Ungroup | Command G / Command Shift G |
| Frame selection | Command Option G |
| Present | Command Option Return |
| Zoom in / out | Command + / Command - |
| Zoom to 100% | Command 0 |
| Zoom to fit / selection | Shift 1 / Shift 2 |
| Move | V |
| Hand | H; hold Space to pan temporarily |
| Scale | K |
| Rectangle / Ellipse / Line | R / O / L |
| Pen / Pencil | P / Shift P |
| Edit Path | A |
| Frame / Section / Slice | F / Shift S / S |
| Text | T |
| Comment | C |
| Nudge | Arrow key; Shift plus arrow moves 10 px |
| Cancel current interaction | Escape |

These bindings come from `assets/keymaps/default-macos.json` and canvas handlers in `crates/fig_viewer/src/view.rs`. Tool or operating-system settings may alter what reaches the canvas.
