# Editor surfaces

## Canvas and Layers

The canvas shows the active page and its selectable layers. The Layers panel lets you select and range-select layers, expand groups, rename nodes, toggle visibility and locking, and drag layers above, below, or inside other nodes. Its context menu includes duplicate and delete, copy as SVG or PNG, copy properties, move to page, group and ungroup, frame or section conversion, flatten, outline stroke, mask, media replacement and cropping, layout, and component actions. The available actions depend on the layer.

The Pages area of Layers creates, selects, renames, duplicates, reorders, and deletes pages. It also includes a page link action and name/text search and replace.

## Variables

The Variables workspace manages collections, modes, values, aliases, and bindings. Create a collection and variable, set mode values, then bind compatible selected layer properties. Scope a mode to preview a different value set.

## Code

The Code workspace displays source files from the local project. FNX source is editable. When you begin editing, Fanta locks canvas edits until you save or leave the dirty source state. Saving validates the project, writes the source and sidecar, then reloads the canvas. Errors appear in the editor. The JSON view is a read-only preview.

## Prototype and comments

Use the Prototype inspector controls to connect triggers and actions, then **Present** to test the flow. The Comments mode and tool provide an annotation surface.

Fanta has a live local design tool interface for agents. Its operations cover creating common nodes, changing style and layout properties, and inspecting structure; it does not use a required fixed HTTP port. See [agent integration](/docs/plugin) for the current setup if present in this documentation site.

Layer behavior is in `crates/fig_viewer/src/design_panel.rs` and `crates/fig_viewer/src/layer_context_ops.rs`. Variables and Code are in `crates/fig_viewer/src/variables_workspace.rs` and `crates/fig_viewer/src/code_workspace.rs`.
