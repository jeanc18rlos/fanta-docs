Fanta's Settings window groups everyday preferences and account controls. The available actions depend on the build and the signed-in account.

| Area | Current controls |
| --- | --- |
| General | Startup view, autosave, quit confirmation, and system file dialogs. |
| Appearance | Color and icon themes, interface text size. |
| Canvas | Show or hide Layers, Inspector, Files, Git, and Threads panels. |
| Editor | Cursor and line-number settings, FNX source text size, keyboard shortcuts. |
| AI & Models | Open the Agent Panel and configure model providers. |
| MCP & Tools | Toggle Fanta hosted tools or the live canvas MCP server; manage configured MCP servers. |
| Account, Billing, and Privacy | Account links, credit and plan views when available, diagnostics and usage controls, legal links. |

## MCP connections inside Fanta

The **MCP & Tools** page separates Fanta's hosted tools, the live canvas server used by external clients, extension tools, and MCP servers that the in-app agent can call. For the last group, Fanta can save a server globally or for a workspace, add or edit it, enable or disable it, authenticate, retry, remove it, and show connection status. Supported connection types include a local command and a remote HTTP endpoint. [Connect an external agent to Fanta's canvas →](/docs/mcp/connect)

The Mac App Store feature build cannot launch local command-backed MCP servers, external agent processes, terminal commands, or external formatters from inside Fanta. Remote project connections are also disabled. Its MCP settings direct you to remote HTTP servers instead. This restriction does not remove the live canvas server toggle or prove that an external client cannot connect to the Store build; that inbound path needs build-specific verification. Non-Store builds retain the local command option.

## Account and privacy

Billing views show account state, credit balance, usage, plans, and activity when the service provides them. Usage can be viewed over a selected time range and exported as CSV. The App Store feature build offers Apple purchase, restore, sync, and offer-code actions when configured; a non-Store build uses its configured browser checkout flow. For an eligible App Store Pro introductory trial, the plan displays its trial duration and localized price after the trial, and the action says **Start free trial**. The trial grants Pro access but adds no subscription credits; existing account credits remain usable. Subscription credits begin with each paid month, and Apple manages cancellation. Exact products, prices, eligibility, and account entitlements come from the live service or store. Deleting a Fanta account in the Store build is a separate action from canceling an Apple subscription.

Privacy controls include crash diagnostics and anonymous usage metrics. The App Store feature build also describes macOS access to user-selected files, saved sign-in, and network services under **App Access**. See [Install and build](/docs/getting-started/install) for distribution status and setup.
