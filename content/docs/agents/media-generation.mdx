title: Media generation
description: Generate, preview, save, and place hosted image, video, audio, and vector results.
---

Fanta's Generation Workspaces expose **Image**, **Video**, **Audio**, **Vector**, **Design**, and **Masks** modes. Hosted generation requires sign-in. The app loads a searchable model catalog from the service, so the available models, controls, account access, and credit estimates can change.

## What each mode does

| Mode | Typical work |
| --- | --- |
| Image | Create an image from text or use an image and mask as inputs. |
| Video | Generate from text or animate an image. |
| Audio | Create speech or music. |
| Vector | Create an SVG from a prompt or trace an image. |
| Design | Prepare a design request for review in the Agent Panel. |
| Masks | Create or refine a mask for a supported image workflow. |

Starter templates help begin image, video, audio, and SVG requests: editorial and product images, cinematic and atmospheric video, narration and music, or a geometric symbol and monogram. Pick a model and recipe before setting its controls. Fanta reads the selected model's capabilities to show relevant options, such as video duration, resolution, audio, camera controls, or an optional ending frame. The supported inputs and output formats depend on that model. A source image can come from a local PNG, JPEG, or WebP file or a captured canvas region where the recipe permits it. Check the controls and estimated cost shown before submitting.

## Review and save a result

Select an output to preview it. On macOS, the result view can play generated video and audio. The audio player shows the decoded duration before playback and supports seeking, ten-second jumps, speed, mute, and volume controls. **Save result** writes the chosen output to a file you select; Fanta can use media already loaded for the preview. In a Mac App Store build, the Save dialog grants access to the selected destination.

Recent experiments use a descriptive creation title when the service can provide one, with a local prompt-based label as fallback.

An output in the generation history is separate from the current design until you add it. You can reuse supported raster results as a source for another run. A mask is used in a supported masking workflow and cannot be added to project Assets as a standalone canvas asset. Design mode prepares a prompt for the Agent Panel; it is not a direct generative canvas render.

## Add a result to a project

With a project canvas open, choose **Add to project** for a supported result. Fanta copies it into the project's asset storage and records its name and kind in the persistent asset library. Open **Assets** in the file inspector, choose the target under **Place in**, and use the **+** button on the asset row. You can place the same stored asset again without repeating the generation.

| Result | Project placement |
| --- | --- |
| PNG, JPEG, or WebP | Bitmap image layer |
| Supported SVG | Editable vector content |
| MP4 | Video layer |
| WAV, MP3, or FLAC | Audio layer |

The placed media is centered in the visible viewport and scaled to fit. On macOS, select an audio or video layer in **Motion** or **Prototype** mode to use its playback controls. See [Project Assets](/docs/editor/assets) for the full workflow and limits. Some generation views also offer **Add to design** directly for image, SVG, or video results. Even if that direct button appears beside audio, use the project Assets route: the direct path does not decode audio for placement.

<Callout type="info">
Adding or placing an asset requires an editable project. Save or discard unfinished FNX source edits first. Model availability, credits, and prices are live service conditions; this page describes the app workflow rather than a fixed catalog or guaranteed price.
</Callout>
