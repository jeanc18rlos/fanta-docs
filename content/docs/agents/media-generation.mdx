Fanta's Generation Workspaces expose Image, Video, Audio, Vector, Design, and Masks modes. Generation uses hosted models and requires sign-in. The app loads the available models from a live catalog, so specific models, prices, and parameters can change.

## What each mode does

| Mode | Typical work |
| --- | --- |
| Image | Text-to-image generation, with optional source image and mask workflows |
| Video | Text-to-video or image-to-video generation |
| Audio | Speech and music generation |
| Vector | Prompt-to-SVG and image-to-SVG or vectorization workflows |
| Design | Draft a design request for review in the Agent Panel |
| Masks | Create or refine an image mask for supported generation workflows |

Generation recipes depend on the selected model. The workspace may accept a local PNG, JPEG, or WebP source, or capture a region of the current canvas. Check the selected model's requirements in the app before submitting. Costs and available outputs are shown by the live catalog and account state.

## Use a result

Generated results can be saved and reused. Images can be placed into a Fanta project. SVG results can be inserted as editable vector content. Generated video can become a video node. Audio output can be saved, but the current canvas-placement flow does not add it as an audio layer. Design mode prepares a prompt for the Agent Panel; it is not a direct generative canvas render.

A hosted result remains distinct from the project until you add or save it. Review the generated media, choose the useful output, then inspect its placement and cropping on the canvas.
