---
title: In-app AI
description: Work with an agent from Fanta's Agent Panel and review changes on the canvas.
---

Fanta includes an Agent Panel for design work inside the desktop editor. The panel can read the current design state, make structured edits, capture screenshots, and place generated images. This keeps the request and the editable result in the same workspace.

## Start with the document

Open a Fanta project or imported Figma file, then describe the specific page, frame, or selection you want changed. Give the agent dimensions, content, style, and constraints where they matter. Ask it to inspect the current design before changing existing work and to show a screenshot after its edit.

The built-in design tools include <code>design_state</code>, <code>design_edit</code>, <code>design_screenshot</code>, and <code>place_generation</code>. The edit tool uses the same ordered design-operation model as the local MCP edit surface. An operation batch is undoable and rolls back if an operation fails. The placement tool can fetch a generated image URL and put the image into the project.

## AI provider and account

Fanta's default settings include a managed Fanta AI provider. After sign-in, the provider reads the current chat-model catalog from the service and shows each model's supported tools, images, context size, and credit information when supplied. The app also exposes settings for connecting your own supported provider credentials. Provider availability and model choices can change, so inspect **Settings → AI & Models** for the options available to your account.

The built-in agent also registers `evaluate_with_jev` for typed decisions about supplied text or structured state. It can ask one to eight named boolean, choice, or score questions and returns structured answers instead of a chat reply. The request is limited to 8 KiB, requires Fanta sign-in, and is unavailable in restricted agent mode. The tool describes a minimum charge of one Fanta credit for a successful call; actual availability and billing depend on the connected service. This is an in-app agent tool, not one of the six external canvas MCP tools.

Hosted generation is a separate model catalog and credit workflow. It requires sign-in; some jobs require credits. See [media generation](/docs/agents/media-generation) and [Settings](/docs/editor/settings).

## Review what changed

Inspect the updated layers and screenshot in the editor. You can continue with manual canvas tools, request another revision, or undo an edit batch. If a request needs a gradient, variable, or per-run rich-text edit unavailable through structured operations, work through [FNX source](/docs/formats/fnx).

<Callout type="info">
The local MCP server and Agent Panel both work with the open desktop design, but their tool names and exact capabilities differ. Fanta does not expose a universal external-agent orchestration or live multi-user cursor system through these tools.
</Callout>
