---
title: Your First Project
description: See how a canvas edit becomes .fnx source and a Git diff.
---

1. Choose **File → New Design…** and select a new folder, or **File → Open…** to import a Figma `.fig`. An import creates a Fanta project folder beside the original file.
2. Draw a rectangle or frame. About a second after editing stops, Fanta saves the change into the project folder. The working source is under `pages/`, not inside the original `.fig`.
3. Open the **Code** workspace to inspect and edit the page's `.fnx`. Save valid source to reload the canvas. You can also edit the file in another code editor; the open canvas reloads shortly after save.
4. Choose **File → Review Changes** or inspect `git diff`. Use **File → Commit…** when the screenshot and source diff agree. Fanta initializes Git when it is available, unless the project is already inside a repository.

Let a canvas edit autosave before modifying the same nodes in `.fnx`, and let source reload before continuing on canvas. Leave `*.ids.json` sidecars and `fanta.json` to Fanta. Without Xcode Command Line Tools, a project can save without Git initialization; install the tools or run `git init` yourself.
