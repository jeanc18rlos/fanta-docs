## Install the non-Store alpha

The documented alpha DMG targets Apple Silicon. macOS 26.6.2 is the version recorded in its release rehearsal; Intel and other macOS versions have not been verified for that DMG. Download the alpha DMG from Fanta's release channel, open it, and drag Fanta to Applications. The documented bundle is ad-hoc signed. If macOS blocks first launch, try opening it, then use **System Settings → Privacy & Security → Open Anyway**.

The source also contains a separate Mac App Store feature build. Its packaging checks require macOS 12.0 or later, but a package or review build does not establish a public Store release. Check Fanta's official distribution channel for availability. The DMG and external-agent commands in this guide describe a non-Store build.

## Build from source

Clone the [fanta-edit repository](https://github.com/jeanc18rlos/fanta-edit), install its Rust and macOS build dependencies, and run from the repository root:

~~~bash
cargo run -p zed
~~~

The Cargo package is <code>zed</code>; its binary is <code>fanta</code>. Use <code>cargo build --release -p zed</code> for a release binary. The repository uses <code>./script/clippy</code> for linting.

## Mac App Store build differences

A build compiled with <code>mac_app_store</code> is sandboxed. It does not ship the CLI helper or bundled Git runtime and does not automatically initialize Git repositories. It cannot launch command-backed MCP servers, external agent processes, terminal tasks, or external formatters from inside the app, and remote project connections are disabled. Remote HTTP MCP servers remain available. Purchase, restore, and offer-code actions use Apple's in-app purchase flow in this build; non-Store builds use web checkout.

The in-app live canvas MCP server is a separate setting, but an external client's bridge to a packaged Store build still needs validation. File access follows macOS user-selected Open and Save permissions. See [Settings and build differences](/docs/editor/settings).
