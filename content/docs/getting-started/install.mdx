## Install the alpha

The current DMG targets Apple Silicon. macOS 26.6.2 is the only version recorded in the release rehearsal; Intel and other macOS versions are unverified. Download the alpha DMG from your Fanta release channel, open it, and drag Fanta to Applications. The bundle is ad-hoc signed. If macOS blocks first launch, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it. See the [release notes](https://github.com/jeanc18rlos/fanta-edit/blob/main/docs/alpha/RELEASE_NOTES.md).

## Build from source

Clone the [fanta-edit repository](https://github.com/jeanc18rlos/fanta-edit), install its Rust and macOS build dependencies, and run from the repository root:

```bash
cargo run -p zed
```

The Cargo package is `zed`; its binary is `fanta`. Use `cargo build --release -p zed` for a release binary. The repository uses `./script/clippy` for linting.

Next choose **File → New Design…** or **File → Open…** to import a `.fig` file. See [Your First Project](/docs/getting-started/first-project).
