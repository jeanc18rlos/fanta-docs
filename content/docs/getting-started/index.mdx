Fantaisa is a native Rust creative canvas — a Figma-like, polymorphic infinite canvas where vector, bitmap, text, video, 3D, node graphs, and AI artifacts share the same document semantics: transform, selection, grouping, undo, and export.

What makes it different: **the desktop app is itself a live MCP server.** AI coding agents — Claude Code, OpenAI Codex, GLM — connect to the running editor and design on the real canvas in real time, while you watch.

## Two ways to work

<Cards>
  <Card title="Design by hand" href="/docs/getting-started/first-project" description="Open the editor, create a page, draw frames, and save. The classic direct-manipulation canvas." />
  <Card title="Design with an agent" href="/docs/getting-started/connect-an-agent" description="Point an AI agent at the live editor over MCP and have it build on the real canvas." />
</Cards>

Both paths share one document. An agent can lay out a screen and you can refine it by hand in the same session — or the reverse.
