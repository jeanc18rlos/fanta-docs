title: Getting Started
description: Install Fanta, create a source-backed design, and connect an agent.
---

Fanta is a macOS design editor whose working format is a project folder of `.fnx` source. Canvas edits autosave into that folder; editing the source in your own code editor reloads the canvas. Choosing **File → New Design…** creates `fanta.json`, `pages/`, `components/`, and an `AGENTS.md` seed. Opening a Figma `.fig` attempts to create the same editable project beside the import. Git makes the design reviewable when a repository is available.

This is an Apple Silicon alpha. The release build was driven through MCP, while several mouse and keyboard paths are documented from source and tests. Read the [known issues](https://github.com/jeanc18rlos/fanta-edit/blob/main/docs/alpha/KNOWN_ISSUES.md).
