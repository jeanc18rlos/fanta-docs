title: Getting Started
description: Install Fanta, create a source-backed design, and connect an agent.
---

Fanta is a macOS design editor. Its working document is a project folder with a <code>fanta.json</code> manifest and readable <code>.fnx</code> design source. Canvas edits save into that folder; editing valid source in a code editor reloads the canvas. **File → New Design…** creates the manifest, page and component directories, and project-local <code>AGENTS.md</code>, <code>fanta.md</code>, FNX type declarations, and editor configuration. Use <code>fanta.md</code> to record the design brief, audience, visual direction, foundations, component system, and acceptance checks.

You can also open a Figma <code>.fig</code> file and continue in an editable Fanta project. In a non-Store build, Git can track the source changes. [Your first project](/docs/getting-started/first-project) walks through a canvas edit, its FNX source, and review.

Fanta's local MCP bridge lets an external agent inspect and edit the open canvas. The app copies a connection command for the running installation and its data directory; use that command for your project. [Connect an agent](/docs/getting-started/connect-an-agent) explains the setup.
