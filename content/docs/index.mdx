Fanta is a native design editor built around an ordinary project folder. Canvas edits write readable `.fnx` files; valid source edits update the canvas. If Git is available, those changes can be reviewed and committed like code.

The documented download remains an **Apple Silicon macOS alpha**. These pages track [fanta-edit main at `a022ddb4`](https://github.com/jeanc18rlos/fanta-edit/tree/a022ddb4eb0828dea734584aea8e63e6cb503c05), with build and release limits called out where they matter. Some source capabilities may reach a packaged release later. Start with the [full capability map](/docs/capabilities).

## A first pass

1. Use **File → New Design…** or open a `.fig` file. Fanta creates a native project directory when it can write to the chosen location.
2. Work on the canvas, in the inspector, or in the Code workspace. Valid external `.fnx` edits reload the canvas.
3. Connect an agent to the running app through its local MCP bridge, if you want one.
4. Let autosave update the project files, review the Git diff, then export a page or selection.
