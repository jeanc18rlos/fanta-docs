**Fantaisa** is a native, polymorphic creative canvas — vector, bitmap, text, video, 3D, node graphs, and AI artifacts all share the same document semantics (transform, selection, grouping, undo, export).

What makes it different: **the app is itself a live MCP server.** AI coding agents — Claude Code, OpenAI Codex, GLM — connect to the running editor and design on the *real* canvas, with the same tool surface the in-app AI brain uses. Every change is an undoable operation. You watch it happen.

<Callout type="info">
  New here? The fastest path is the [60-second agent quickstart](/docs/getting-started/connect-an-agent) — launch the editor, point your agent at `http://127.0.0.1:3846/mcp`, and start designing.
</Callout>

## Built LLM-first

These docs are designed to be read by machines as easily as by people:

- Every page has a Markdown twin — use the **Copy Markdown** / **Open in** buttons at the top of any page.
- A curated [`/llms.txt`](/llms.txt) index and a full [`/llms-full.txt`](/llms-full.txt) dump let an agent ingest the whole site in one fetch.
- The [Tool Reference](/docs/tools) mirrors the live tool schemas the editor exposes on `:3846`.

See [Reference → LLM-first docs](/docs/reference/llms) for details.
