---
title: The build loop
description: Inspect, edit, verify, and review a source-backed Fanta design.
---

1. **Orient:** call `get_guidelines`, then `get_editor_state`. Check the project, focused page, selection, and editability. For a new top-level frame, pass `empty_space: [width, height]`.
2. **Inspect:** call `batch_get` for the page tree. Its default listing includes up to 200 direct children at depth 2. Follow `more_children` with `offset` and `limit`, and fetch exact IDs for detail.
3. **Edit:** call `batch_design` with `ops` and a descriptive `label`. Its operations run in order as one undoable transaction. Failure rolls back the whole batch; use returned created IDs in follow-up calls.
4. **Verify:** call `get_screenshot`, preferably for the changed node. Inspect the PNG, adjust with another batch, and capture again.
5. **Review:** allow autosave, inspect the `.fnx` Git diff, then commit the intended change.

For bulk text or styling beyond the operation vocabulary, locate the complete `.fnx` source with `read_fnx_source`, edit it with ordinary file tools, and let Fanta reload before more canvas work on the same nodes.
