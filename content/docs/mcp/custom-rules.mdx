---
title: Custom rules & project context
description: Keep design conventions beside the project source.
---

A new Fanta project includes an `AGENTS.md` seed. Put project-specific naming, spacing, type, component, and verification conventions there. Agents that can read the project folder can use it alongside the live `get_guidelines` response.

```md
# Design conventions

- Use the existing button component for primary actions.
- Name top-level frames by screen and state.
- Screenshot each changed screen and inspect the Git diff.
```

`get_guidelines` describes the current coordinate system, batch workflow, and source editing rules. Read it at the start of a session. Project instructions should add local choices; they do not change the live tool schema. Review an agent’s proposed `.fnx` diff before committing.
