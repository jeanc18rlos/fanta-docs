---
title: Troubleshooting
description: Diagnose connection, large results, and source reload issues.
---

## The client cannot connect

Open Fanta and focus a design before starting `fanta --mcp-stdio`. Check the binary path and `fanta_live_mcp.enabled` setting, then restart the client. The bridge exits when the app is closed or MCP is disabled.

## The wrong design is active

`get_editor_state` reports the active page and selection. Focus the intended design and read state again. The server acts on the most recently focused canvas.

## A tree query is refused

`batch_get` caps responses at 256 KiB. Use smaller `limit`, `offset`, lower `depth`, or fewer exact IDs. A wide imported `.fig` page can have thousands of siblings.

## Source looks incomplete

`read_fnx_source` returns at most 64 KiB by default. Follow `truncated` and `next_offset`; use a larger `max_bytes` for an unusually long line (ceiling 1 MiB). Never replace a file based on a partial slice.

## Source did not reload

Save the `.fnx` file in the open project, keep its syntax well formed, and allow the reload. Leave generated `*.ids.json` files alone. Fanta logs live at `~/Library/Logs/Fanta/`.
