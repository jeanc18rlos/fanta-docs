---
title: MCP Server
description: Six tools connect external agents to the focused Fanta design.
---

Fanta’s MCP server is part of the running desktop app. It uses a private Unix socket, and `fanta --mcp-stdio` bridges stdio clients to it. It acts on the most recently focused design.

| Tool | Purpose |
| --- | --- |
| `get_editor_state` | Read project, pages, selection, viewport, and empty-space placement. |
| `get_guidelines` | Read the design rules maintained with the operation schema. |
| `batch_get` | Read exact nodes or a paged page tree. |
| `batch_design` | Apply typed operations as one undoable transaction. |
| `get_screenshot` | Render a page or node region as PNG. |
| `read_fnx_source` | List or read source files in the open project. |

The built-in Agent Panel uses the same `design_surface::DesignOp` vocabulary through its own tools. External MCP clients see these six tools, rather than a tool for every design operation.
