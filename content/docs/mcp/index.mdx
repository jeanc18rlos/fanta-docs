---
title: MCP Server
description: Thirteen tools connect external agents to the focused Fanta design.
---

Fanta’s MCP server is part of the running desktop app. It uses a private Unix socket, and `fanta --mcp-stdio` bridges stdio clients to it. It acts on the most recently focused design.

The connection instructions below are for a non-Store build. Fanta's Settings can also configure local or remote MCP tools for its own in-app agent. The Mac App Store feature build blocks Fanta from launching local MCP commands, while remote HTTP tools remain available. That is a different direction from an external client connecting to Fanta's live canvas server. [Build differences →](/docs/editor/settings)

| Tool | Purpose |
| --- | --- |
| `get_editor_state` | Read the active project, pages, selection, viewport, and free placement space. |
| `get_design_system` | Inspect components, variants, variable collections, modes, values, and selected-node bindings. |
| `prepare_design_asset` | Open a draft image or SVG generation request for the user to review and submit. |
| `batch_get` | Read exact nodes or a paged page tree. |
| `batch_design` | Apply typed operations as one undoable transaction. |
| `get_screenshot` | Render a page, node, or motion-clip sample as PNG. |
| `read_fnx_source` | List or read source files in the open project. |
| `validate_fnx_source` | Check a complete FNX or managed design-system JSON candidate without writing it. |
| `get_guidelines` | Read design, source-editing, and project-specification guidance. |
| `import_image` | Save an image from a file, URL, or base64 source into project Assets. |
| `list_comments` | Read canvas comment threads on a page. |
| `reply_comment` | Reply to a thread and optionally resolve it after verification. |
| `report_agent_activity` | Show an agent's current canvas or source-file activity. |

The built-in Agent Panel uses the same `design_surface::DesignOp` vocabulary through its own tools. External MCP clients see these thirteen tools, rather than a tool for every design operation. Read the [tool reference](/docs/tools) for the operation list.
