Fanta's editable document is a project directory with a <code>fanta.json</code> manifest. In layout version 5, each variant set has one folder containing its set definition and member masters. Pages, standalone components, variables, metadata, and assets also live in separate files. The persistent [Project Assets](/docs/v2/editor/assets) library can store named media before it is placed on a page. A canvas edit updates the affected project files, and valid saved source changes reload in the canvas.

## Choose the right output

| Format | Main purpose | Editable in Fanta? |
| --- | --- | --- |
| [Fanta project directory](/docs/v2/formats/fant) | Continue designing and version source and assets in Git | Yes |
| [<code>.fant</code> snapshot](/docs/v2/formats/fant) | Package a design and its assets as one file | Import into an editable project |
| [<code>.fnx</code> source](/docs/v2/formats/fnx) | Review or edit a page or component master as static JSX-like source | Yes, within a project |
| [<code>.fig</code> import](/docs/v2/formats/figma-import) | Bring an existing Figma design into Fanta | Imported into an editable project |
| [PNG, JPG, SVG, PDF](/docs/v2/formats/export) | Share a visual result | Rendered output |
| [Motion exports](/docs/v2/formats/export#motion-exports) | Move one clip's animation to another workflow as JSON, a Claude Motion Stage package, MP4, GIF, or PNG frames | No; keep the project to edit it |
| [Compiled `.fanta` runtime bundle](/docs/v2/formats/runtime-bundle) | Play a compiled design with a matching runtime from source | No; keep the project to edit it |
| [Static website](/docs/v2/formats/website-export) | Publish read-only design pages with a matching WebAssembly runtime (command-line tool) | No |

The Code workspace can edit FNX and its selected page or component JSON header when the canvas is clean, validate the complete project, and reload the canvas on save. An external editor or agent can edit other managed project files too; validate typed JSON and references before writing. New projects include a <code>fanta.md</code> design brief, <code>AGENTS.md</code> editing guide, and FNX editor support files.

## Save and version

Keep the project manifest, page and component source, ID sidecars, shared document data, asset library metadata, and media bytes together in Git. An external file edit is reconciled into the open editor; invalid source leaves the last valid canvas visible with a diagnostic. If a canvas change and file change overlap, Fanta presents a conflict.

**File → Save As…** creates a new local project copy, including current edits and assets, and points subsequent saves to that copy. The original project stays intact. The <code>.fant</code> handler supports import and export at the format layer, but a snapshot is not the editable working directory. The editor's export controls produce visual and motion files, and a separate website-export command publishes read-only pages; neither replaces the editable project. See [project and snapshot details](/docs/v2/formats/fant).
