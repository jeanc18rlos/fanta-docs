These pages track [fanta-edit main at `389e8c9`](https://github.com/jeanc18rlos/fanta-edit/tree/389e8c905d14168b808af5fd5ce058cf2c3d2ba3), the in-development Fanta 2.0: a native macOS editor with a source-backed project format and a 14-tool external MCP server. Fanta 2.0 has no installer yet. The source also has an unpublished [Rust Design API](/docs/v2/reference/design-api); it is not a hosted public API.
