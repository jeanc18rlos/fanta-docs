These pages track [fanta-edit main at `d4fe647`](https://github.com/jeanc18rlos/fanta-edit/tree/d4fe64713e8615607878d896049f88379e7cc39f), the in-development Fanta 2.0: a source-backed editor with a 14-tool external MCP server. Fanta 2.0 has no accepted installer yet. The source also has an unpublished [Rust Design API](/docs/v2/reference/design-api) and a [runtime bundle compiler](/docs/v2/formats/runtime-bundle); neither is an accepted public SDK.
