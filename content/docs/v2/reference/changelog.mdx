This changelog lists what changed in Fanta 2.0's source after the 1.0 Public Alpha. Fanta 2.0 has no installer yet. Earlier history is in the [Fanta 1.0 changelog](/docs/reference/changelog).

## October 26, 2026 source alignment

These pages now track published [fanta-edit main at `389e8c9`](https://github.com/jeanc18rlos/fanta-edit/tree/389e8c905d14168b808af5fd5ce058cf2c3d2ba3). The signed, installed Public Alpha remains **Fanta 1.0.0 Build45** from source `57d86330`; the changes below are committed 2.0 source, not an accepted 2.0 installer or deployed cloud service.

Text and TextPath layers can resolve `{{name}}` or `{{Collection/Name}}` tokens from text-like variables while keeping the authored tokens in source. Template rules can restrict layer edits. The editor's **Fill mode** now checks canvas gestures, Delete, Duplicate, text editing, and Design inspector changes against these rules. The inspector does not show or edit rules, placeholders have no overlay, and multi-selection, binding, and grouping paths do not fully enforce them. [Templates and inline variables →](/docs/v2/capabilities#templates-and-inline-variables)

The new in-process Rust `fanta-api` supports typed property reflection, node edits, explicit undo steps, polled node events, roles and scopes, placeholders, template filling, and batch export. The source-only `fanta-engine` worker adds ordered project inspection, editing, rendering, commenting, template fill, batch PNG export, and changeset steps. These do not add local MCP tools or establish a hosted public API. The renderer adds 26 layer blend modes and group Pass through; SVG draws blend modes as Normal and PDF falls back to Normal for several new modes. [Architecture →](/docs/v2/reference/architecture) · [Export limits →](/docs/v2/formats/export)

## October 21, 2026 source alignment

These pages now track published [fanta-edit main at `578c1283`](https://github.com/jeanc18rlos/fanta-edit/tree/578c12839286b62f2fafabc134a56929ab3ef60e). It still declares **Fanta 2.0.0**, and the accepted signed Public Alpha remains **Fanta 1.0.0 Build45** from source `57d86330`.

The Design menu now also exports the selected animation as a Claude Motion Stage package, an MP4 video, a GIF, or PNG frames. Fanta renders them itself; MP4 needs `ffmpeg`. [Motion exports →](/docs/v2/formats/export#motion-exports) On macOS, canvas images now decode on background threads at the size they are drawn. An image can show a light grey wash, or look soft, for a moment. In a bounded release-build measurement on a page of 24 large photos, the slowest canvas render dropped from 1.9 s to 64 ms; that does not establish general responsiveness.

Current source builds and runs its tests on Windows in CI. Linux and Windows installers, and cloud AI Review and generation, are in development; none is offered in a build. The shared engine code they need now lives in separate crates (`fanta-design-ops`, `fanta-headless`, and the in-development `fanta-engine`), without changing what the editor does. The external MCP server still registers 14 tools, and `batch_design` still exposes 44 operations. [Roadmap →](/docs/v2/roadmap)

## October 20, 2026 source alignment

These pages now track published [fanta-edit main at `2136e0d2`](https://github.com/jeanc18rlos/fanta-edit/tree/2136e0d2d7ae6a02b20341725efc6961df16a8fb). Its Cargo package declares **Fanta 2.0.0**, while the accepted signed Public Alpha remains **Fanta 1.0.0 Build45** from source `57d86330`. The source changes do not establish a v2 installer, signed update feed, or installed-app acceptance.

The source adds enum and image variables, conditional prototype actions and variable arithmetic, Motion clip settings and portable/Figma Motion JSON export, expanded vector path editing, anchored AI Review findings with explicit undoable suggested fixes, and a command-line static website exporter that requires a matching runtime from Fanta-JS. It also adds update controls in Settings, About, and the app menu. Presentation-engine changes add Contain, Cover, and Fill fit modes and preserve the backdrop behind overlays; a matching editor control was not verified. The website viewer is read-only; prototype interactions and Motion playback are disabled there. Stage JSX, MP4/GIF export, trigger inputs, and a state-machine view are not implemented in this interval.

The external canvas MCP server now registers **14 tools** after adding `add_comment`. Agent comments can anchor to a layer and include review severity, category, run ID, and an optional suggested content-editing fix. `batch_design` now exposes **44 operations**, adding `set_variable_options` for enum variables. This source checkpoint does not change the accepted Build45 recording or the public installer instructions.

## October 19, 2026 source alignment

These pages now track published [fanta-edit main at `e143440a`](https://github.com/jeanc18rlos/fanta-edit/tree/e143440a93732422ac37c6ad1901ff14c420ec7b). Changes merged after the previous checkpoint renamed the app's Cargo package and action namespace to `fanta`, its project-local configuration directory to `.fanta`, and its app link scheme to `fanta://`. The repository now builds explicitly with `cargo run -p fanta`; plain `cargo run` works through the workspace default. The local canvas MCP roster remains 13 tools with 43 design operations; no new format or generation behavior was found in this source interval.

The accepted signed Build45 installer is still bound to earlier source `57d86330`. It uses `.zed` project settings, `zed::` app actions in keymaps, and `zed://` app links. Current source uses `.fanta`, `fanta::`, and `fanta://`. Custom configuration and links should be reviewed when moving to a future build; automatic migration and a newer public installer have not been verified.

## October 15, 2026 source update

These pages track published [fanta-edit main at `44584c26`](https://github.com/jeanc18rlos/fanta-edit/tree/44584c26eebb91b1ae97dd07a6715cb22ef289ee). The signed Fanta 1.0.0 Public Alpha installer remains bound to earlier source `57d86330`; this source update is not a new accepted app build.

External MCP still registers 13 tools. `get_editor_state` now previews at most 100 components and reports the total and whether more remain. `get_design_system` pages variables, components, and variant sets independently, and `batch_get` rejects page listings whose traversal exceeds 1,000 nodes. Default page reads and screenshots follow the focused page or opened component. A `batch_design` batch containing only selection or viewport operations does not create an undo step; content edits still commit as one undoable batch.

Current macOS source prefers Skia Graphite on Metal, with Ganesh fallback if Graphite cannot start. Retained translation is enabled unless `FANTA_RETAINED_TRANSLATION=0`. Loading, scoped saving, canvas panning, and memory use have changed for large documents. Bounded benchmarks and source tests do not establish general responsiveness or behavior in the released Build45 installer. Native builds route new AI credit purchases to web Billing; existing Apple subscriptions still open Apple's subscription management.
