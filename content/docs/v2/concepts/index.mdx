# Concepts

Fanta is a visual design editor built around a local, editable project. A project contains pages, reusable components, assets, variable collections, and a source representation of its layers. You can work on the canvas, in the inspector, or in the Code and Variables workspaces.

Start with [the document model](/docs/v2/concepts/document-model) to understand what is saved. Then explore [pages and coordinates](/docs/v2/concepts/pages-world-space), [auto layout](/docs/v2/concepts/auto-layout), [components](/docs/v2/concepts/components), [variables](/docs/v2/concepts/variables), [templates and Fill mode](/docs/v2/concepts/templates), [vectors and SVG](/docs/v2/concepts/vectors-icons-svg), and [prototyping](/docs/v2/concepts/prototyping).

If you want to inspect the design as source, see [FNX](/docs/v2/concepts/fnx-design-as-source). Source editing is available in the Code workspace, with validation and a canvas reload when you save. The editor also keeps a readable JSON view.

Fanta includes imported node types and effects whose editor support varies. The pages here describe the working controls and point out known limits so you can choose a reliable workflow.
