## Color and typography

The docs carry the dark foundation and periwinkle/lime accents from Fanta's existing presentation identity. Light mode uses an ivory reading surface.

| Color | Value | Use in the docs |
| --- | --- | --- |
| Ink | `#05070b` | Dark reading surface and the dark mark |
| Ivory | `#ededed` | Main text on dark surfaces |
| Periwinkle | `#8191ff` | Accent family; lighter or darker shades maintain readable contrast |
| Lime | `#d8ff78` | Primary action in dark mode |

**Geist** is the interface and reading typeface. **Geist Mono** is used for FNX, paths, and small labels. Both match the existing Fanta website typography. The layout keeps screenshots large enough to inspect and makes documentation links easy to find.

## Writing about Fanta

Describe the workflow concretely: draw on the canvas, save readable source, review a change. Call FNX **design source** and explain that it is a static format. State which capabilities are available in a build and which are [planned](/docs/v2/roadmap). Comparisons with other tools should describe the [differences in workflow](/docs/v2/fanta-vs-figma) and supported behavior.
