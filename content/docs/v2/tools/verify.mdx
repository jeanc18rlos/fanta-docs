---
title: Export & visual verification
description: Use PNG screenshots for MCP review and the editor UI for exports.
---

`get_screenshot` renders the active page to PNG. Pass `page` for another page, `node` for a node region, or `max_dimension` to cap its longer side (default 768 px, maximum 1568 px). Pass an exact `motion_clip` ID from `get_editor_state.motion_clips` and a `playhead_ms` sample time to inspect authored motion. The result is MCP image content, so an agent can inspect the actual rendered design.

After `batch_design`, screenshot the changed frame, compare it with the intended layout, make a targeted correction, and inspect another screenshot. Review the `.fnx` diff after autosave. A successful operation response alone is not a visual check.

The external MCP server has no `export_png`, `export_svg`, `export_motion`, `compare_screenshot`, or `review_design` tool. The editor export UI writes PNG, JPG, SVG, and PDF under the project's `exports/` directory, and the Design menu exports the active clip as Motion JSON, Figma Motion JSON, a Claude Motion Stage package, MP4, GIF, or PNG frames. Use the UI for file output; `get_screenshot` is the MCP verification tool. [Export formats →](/docs/v2/formats/export)
