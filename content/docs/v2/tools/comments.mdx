title: Comments and review threads
description: Read, create, and reply to canvas review comments.
---

`list_comments` reads canvas comment threads on the active page. Pass `page` to inspect another page or `include_resolved: true` to include closed threads. Each result includes `resolved_world`, the pin's present canvas position, as well as any layer `anchor`; older clients can still use the saved `world` position. A pin anchored to a layer follows it and falls back to its saved position if that layer is deleted. Read unresolved feedback before revising a reviewed design.

`reply_comment` takes the exact thread `id` from `list_comments`, a `body`, and optional `page`, `author`, and `resolve`. The default author is “Fanta Agent.” Reply with the change or finding; set `resolve: true` only after the requested work is verified on the canvas. Comments are stored with the project page metadata and are separate from visual exports.

## Add a review finding

The `add_comment` MCP tool places a new comment. It needs `text` and either a prefixed layer `node` ID or a canvas `world: [x, y]` point. You can provide `page`; otherwise it uses the active page. With a node, optional `offset: [x, y]` uses the node's local units and defaults to its center. With a world point, Fanta anchors to the layer under it when possible. It returns the new `comment_id`.

For review findings, include a `severity` (`info`, `minor`, `major`, `blocker`), a `category` (`layout`, `typography`, `color`, `accessibility`, `consistency`, `content`, `interaction`, `motion`, `other`), and one `review_run_id` shared by that review's findings. A `suggested_fix` may contain a short `summary` and nonempty `ops` from `batch_design`. Use only content-editing operations; `select` and `set_viewport` cannot be undone as part of a suggested fix. Fanta validates the suggestion when the comment is added. Applying it from the comment thread is an explicit user action that creates one content Undo step; posting a review does not apply the fix.

```json
{"node":"<prefixed-node-id>","text":"The label is hard to read against this fill.","severity":"major","category":"accessibility","review_run_id":"review-example"}
```

The in-app Agent Panel has a related `design_comments` tool. Its newer `create` field accepts the same comment draft. Review mode may create findings and reply to existing threads while leaving scene content unchanged. Plan mode may read threads but cannot create, reply to, or resolve them. See [review and revision](/docs/v2/agents/review-revision).
