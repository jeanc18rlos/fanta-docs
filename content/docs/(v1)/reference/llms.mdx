title: LLM-readable docs
description: Markdown feeds for reading this site and a separate live MCP connection.
---

Agents can read the site through [`/llms.txt`](/llms.txt), [`/llms-full.txt`](/llms-full.txt), the **Copy Markdown** button on each page, or page Markdown URLs under `/llms.mdx/docs/`. Source Markdown lives in the [fanta-docs repository](https://github.com/jeanc18rlos/fanta-docs).

Reading the docs does not give an agent access to a canvas. To make a live design change, start Fanta and [connect to its local MCP server](/docs/mcp/connect). The connected server’s `get_guidelines` response and tool schema describe the current build. For alpha limitations, consult the [known issues](https://github.com/jeanc18rlos/fanta-edit/blob/main/docs/alpha/KNOWN_ISSUES.md).
