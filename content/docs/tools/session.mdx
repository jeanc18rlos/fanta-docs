title: Sessions, input & checkpoints
description: Use undo batches, autosave, and Git milestones.
---

`batch_design` previews its ordered operations one by one while the call runs, then commits them as one named undo step. If an operation fails or the call is interrupted, the preview rolls back. The result identifies a failing operation. Use a descriptive `label` for a single component or coherent section; a whole screen in one batch is harder to follow and review.

Canvas edits autosave to `.fnx` after editing stops. Review the source diff and use Git commits for durable milestones. A dirty Code workspace FNX or JSON buffer locks canvas editing until its draft is saved or discarded. Source Save validates and reloads the project; **Discard draft** reloads the selected buffer from disk. Finish a source edit and its reload before returning to canvas edits on the same nodes.

The external MCP server does not expose pointer-event replay, checkpoints, or `try_edit` tools. Use the editor for manual interaction and the MCP tools for state, node queries, transactional edits, screenshots, source reading, comments, and agent activity.
