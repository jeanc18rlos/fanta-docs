---
title: Sessions, input & checkpoints
description: Use undo batches, autosave, and Git milestones.
---

`batch_design` groups its ordered operations into one named undo step. If an operation fails, the batch rolls back and identifies the failing operation. Use a descriptive `label` for history.

Canvas edits autosave to `.fnx` after editing stops. Review the source diff and use Git commits for durable milestones. When directly editing source files, finish one lane before returning to canvas edits on the same nodes.

The six-tool external MCP server does not expose pointer-event replay, checkpoints, or `try_edit` tools. Use the editor for manual interaction and the MCP tools for state, node queries, transactional edits, screenshots, and source reading.
