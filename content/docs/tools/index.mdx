title: Tool Reference
description: The six external MCP tools and typed operations in batch_design.
---

Fanta's external MCP server acts on the focused design. Connect with `fanta --mcp-stdio`. It exposes **six** tools, not one tool for every editor command.

| Tool | Purpose |
| --- | --- |
| `get_editor_state` | Read project, pages, selection, viewport, editability; optionally ask for `empty_space: [width,height]`. |
| `get_guidelines` | Read current design and source-editing rules. |
| `batch_get` | Read exact nodes or a paged page tree. |
| `batch_design` | Apply typed design ops as one undoable transaction. |
| `get_screenshot` | Render a page or node region as PNG. |
| `read_fnx_source` | List or read source files in slices. |

`batch_design` takes `ops: [{"op":"…",…}]` and an optional `label`. Its current ops are `create_node`, `create_image`, `create_instance`, `set_props`, `set_stroke`, `set_shadow`, `set_text_style`, `set_auto_layout`, `set_index`, `rotate`, `align`, `distribute`, `group`, `frame_selection`, `ungroup`, `duplicate`, `create_component`, `reparent`, `delete`, `select`, and `set_viewport`. Ask your MCP client for the live schema to see every field.
