The external MCP server’s `batch_design` schema has no operation for prototype flows, reactions, transitions, or animation keyframes. Older `create_flow` and `set_reaction` examples are not valid for this alpha server.

## Editor capabilities in unreleased v2 source

The committed v2 prototype model and editor add **Adjust number**, **Toggle boolean**, **Cycle enum option**, and **Conditional** actions. A conditional action can compare a variable, run the first matching branch, or run an otherwise branch. The panel edits simple variable comparisons; compound `all`, `any`, and `not` conditions can exist in the model but show as labels rather than editable fields. The presentation engine evaluates these actions; numeric adjustment ignores a missing, wrong-type, or nonfinite value. These actions are source-backed at `2136e0d2`, but their installed-app journey has not been accepted in the signed Public Alpha. They do not add corresponding operations to external `batch_design`.

Authored animation clips live in `doc/motion.json`, apart from page `.fnx` nodes. Read the existing schema before editing clips, tracks, or keyframes with file tools, preserve IDs, and validate screenshots at several `motion_clip` / `playhead_ms` samples. The external MCP tools can inspect motion samples, but cannot author a clip through `batch_design`. Check the current app and [known issues](https://github.com/jeanc18rlos/fanta-edit/blob/main/docs/alpha/KNOWN_ISSUES.md) for UI readiness.
