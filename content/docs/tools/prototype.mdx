---
title: Prototyping & interactions
description: Current MCP boundary for prototype and motion work.
---

The external MCP server’s `batch_design` schema has no operation for prototype flows, reactions, transitions, or animation keyframes. Older `create_flow` and `set_reaction` examples are not valid for this alpha server.

Fanta has prototype and motion panels in its editor source, but visible controls vary in readiness. Check the current app and [known issues](https://github.com/jeanc18rlos/fanta-edit/blob/main/docs/alpha/KNOWN_ISSUES.md) before relying on a UI path. Keep intended interaction behavior in project notes or source review until you have verified an editing path in the build you use.
