---
title: Style, typography & design tokens
description: Apply supported styles and know the current MCP limits.
---

| `batch_design` operation | Change |
| --- | --- |
| `set_props` | Name, position, size, opacity, first solid fill, corner radius, text, hidden, locked. |
| `set_stroke` | Single outline color, width and alignment; width 0 removes it. |
| `set_shadow` | First drop shadow or all drop shadows with `remove: true`. |
| `set_text_style` | Font family, weight, size, line height, letter spacing, alignment, glyph color for the whole text node. |

Colors use `#RRGGBB` or `#RRGGBBAA`; omitted fields are unchanged. For example:

```json
{"label":"Style title","ops":[{"op":"set_text_style","id":"<text-id>","font_weight":700,"font_size":24,"color":"#202020"}]}
```

The document can express more than this external MCP vocabulary. Variables, gradients, and per-run rich text are not separate `batch_design` ops. Locate the relevant `.fnx` with `read_fnx_source`, read the complete section, edit the file with ordinary file tools, and verify its reload and Git diff. Do not treat a partial source slice as a whole page.
