title: Version control
description: Design git — branches, diffs, scoped tasks, commits, merges, and dev/staging/prod promotion.

Fantaisa has built-in design version control. Agents work inside scoped **tasks** (a page/region lock), commit, then finish the task to merge their work. Channels run `dev` → `staging` → `prod`.

## Tools

| Tool | Purpose | Key parameters |
| --- | --- | --- |
| `vcs_status` | Branch, channel, pending task, dirty/conflict state, design locks | — |
| `vcs_branches` | List branches | — |
| `vcs_diff` | Diff two refs | `from?`, `to?` |
| `vcs_begin_task` | Start a scoped edit task | `provider?`=`"mcp"`, `task_id?`, `page?`, `region?:[x,y,w,h]`, `allow_globals?` |
| `vcs_commit` | Commit pending changes | `message?`=`"Fanta edit"` |
| `vcs_finish_task` | Finish and merge the current task | `message?`=`"Agent task"` |
| `vcs_abort_task` | Abandon the current task | — |
| `vcs_merge` | Merge a source branch | `source`, `target?`=`"dev"` |
| `vcs_promote` | Promote a channel | `target`: `"staging"` \| `"prod"` |
| `vcs_checkout` | Switch branch | `branch` |

## Examples

Begin a region-scoped task, commit, and finish:

```json
{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"vcs_begin_task","arguments":{"page":"page-home","region":[0,0,1440,1024],"allow_globals":false}}}
```

```json
{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"vcs_finish_task","arguments":{"message":"Rebuild hero section"}}}
```
