---
title: Components, instances & variants
description: Promote a master and place linked instances.
---

Build a frame or group, read its exact ID, and promote it:

```json
{"label":"Make button component","ops":[{"op":"create_component","id":"<frame-id>"}]}
```

The master stays on canvas and the result returns a component ID. Place a copy with `create_instance`, using the ID or a unique component name:

```json
{"label":"Place button","ops":[{"op":"create_instance","component":"<component-id>","x":400,"y":120}]}
```

An instance inherits its master’s size and follows later master edits. The project stores component source under `components/`, and `get_editor_state` lists component source paths. Variant-set creation and per-instance override editing are not dedicated ops in the six-tool external MCP schema. Inspect existing source and the editor UI before relying on those paths.
