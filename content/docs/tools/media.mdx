---
title: Generation & references
description: Place image bytes and understand the boundary of MCP media editing.
---

The `batch_design` operation `create_image` accepts a `data:image/...;base64,...` URI or raw base64 for an encoded PNG, JPEG, WebP, or GIF. You can provide width or height to preserve aspect ratio, and `meta` to record provenance. Fanta ingests it as an asset under `assets/images/` on save.

`create_image` does not fetch `http(s)` URLs. The six-tool external MCP surface has no `generate_image` or `generate_media` tool. Obtain image bytes through an appropriate provider or use Fanta’s separate generation UI where available. Some toolbar AI commands merely open a draft in the Agent Panel; they do not produce a result until the user completes and sends the prompt.

Inspect imported or placed media on canvas and with `get_screenshot`. See the [known issues](https://github.com/jeanc18rlos/fanta-edit/blob/main/docs/alpha/KNOWN_ISSUES.md) for alpha limitations.
