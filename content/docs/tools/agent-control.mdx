---
title: Agent orchestration & presence
description: Start with live guidelines and state; coordinate agents outside Fanta.
---

Fanta’s six-tool external MCP surface has no `agent_playbook`, agent-team, cursor-presence, or task-lock tool. Start a session with `get_guidelines` and `get_editor_state` to identify the focused design and active page.

If several agents work on one project, assign distinct nodes or `.fnx` files and use one coordinator to review their screenshots and Git diffs. `batch_design` is atomic and undoable, but it is not a cross-agent lock.

The built-in Agent Panel uses design tools and can receive draft prompts from toolbar commands. Those drafts require a manual send and a configured provider. The in-app and external agent interfaces should not be conflated.
