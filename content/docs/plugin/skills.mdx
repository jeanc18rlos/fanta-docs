title: Plugin skills
description: The design, verification, and component skills in the Fanta Claude Code plugin.
---

The plugin ships three Markdown skills. They guide Claude Code; the Fanta app controls which MCP operations are available.

| Skill | Helps with |
| --- | --- |
| `fanta-design` | Inspect the active canvas, make supported changes with `batch_design`, and check the result. |
| `fanta-verify` | Check structure with `batch_get`, view a `get_screenshot` result, inspect `.fnx`, and review Git changes. |
| `fanta-components` | Create a component and linked instances using the available `batch_design` operations. |

The source is under [`plugin/skills`](https://github.com/jeanc18rlos/fanta-docs/tree/main/plugin/skills). See the [tool reference](/docs/tools) for the actual server contract. The plugin adds guidance and configuration, not new Fanta tools.
