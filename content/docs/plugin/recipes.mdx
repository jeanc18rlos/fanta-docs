---
title: Agent recipes
description: Example requests for the Fanta Claude Code plugin and current local MCP tools.
---

These examples assume Fanta is running with a project open and the plugin or [direct MCP connection](/docs/mcp/connect) is active.

## Build a card

```text
/design On the active page, create a 320×180 frame called Welcome card. Add a heading and a primary button inside it. Use auto-layout if needed. Show a screenshot and summarize the .fnx change.
```

## Revise a selection

```text
Inspect the current selection. Change its fill to #4F46E5 and its corner radius to 12. Keep its size and position, then show a screenshot.
```

## Reuse a component

```text
Inspect the selected card, make it a component, and add two linked instances. Verify their names and positions in the document tree.
```

## Review before committing

```text
Inspect and screenshot the active page. Check for unparented layers. Read relevant .fnx source and summarize the design changes visible in Git.
```

The agent can use `batch_get` and `get_screenshot` for verification. Export and commit remain app or filesystem workflows, rather than additional local MCP tools.
