title: Claude Code plugin

The plugin in this repository provides a ready-to-use MCP connection, a `/design` command, and three skills for building and checking designs. It talks to the **running Fanta desktop app** through `/Applications/Fanta.app/Contents/MacOS/fanta --mcp-stdio`.

<Callout type="info">
  The plugin is optional. Claude Code and Codex can also connect directly using the [agent connection guide](/docs/getting-started/connect-an-agent).
</Callout>

## Install

1. Install Fanta in `/Applications`, launch it, and open a design.
2. In Claude Code, run:

```bash
claude plugin marketplace add jeanc18rlos/fanta-docs
claude plugin install fanta@fanta-docs
```

3. Confirm the `fanta` MCP server is connected, then try:

```text
/design Add a 320×180 card with a heading and primary button to the current page.
```

If Fanta is installed elsewhere, update the executable path or [connect directly](/docs/mcp/connect).

The local server exposes [`get_editor_state`, `get_guidelines`, `batch_get`, `batch_design`, `get_screenshot`, and `read_fnx_source`](/docs/tools). The plugin teaches Claude to inspect the live design, make an undoable edit, verify the result, and rely on autosave.

Older plugin versions pointed to an HTTP service on `:3846` and named tools that the current app does not expose. Update or reinstall the plugin if your installed copy still uses that endpoint.
