---
title: FNX design source
description: Read and edit pages and component masters as restricted JSX-like project files.
---

FNX is Fanta's text source for a page or component master. A project stores a page at <code>pages/&lt;slug&gt;/page.fnx</code> and a component master at <code>components/&lt;slug&gt;/master.fnx</code>. Each element is a scene node; literal attributes hold its properties and nested elements hold its children.

## Edit safely

FNX is a restricted, static JSX-like grammar, not arbitrary executable React or JavaScript. Preserve an existing element's <code>id</code> when changing that node. Give a copied or newly created node a new ID. Keep its companion <code>.ids.json</code> sidecar with the project; it records identity and ordering information.

The Code workspace can edit FNX while the canvas is clean. Fanta locks canvas edits while the source buffer is dirty; saving validates the project, writes the source and sidecar, and reloads the canvas. You can also use an external editor or an agent's file tools. The local MCP <code>read_fnx_source</code> tool reads bounded source slices but does not write files.

Canvas edits patch affected source while preserving unrelated comments and whitespace where possible. Invalid syntax or unsupported constructs keep the previous valid canvas visible and show a diagnostic. Fix the source and inspect the rendered result. Fanta can also detect overlapping canvas and external edits and surface a conflict.

## When to use it

Structured agent operations are best for common shapes, layout, text, images, and components. FNX is useful for source review in Git and for properties outside the structured edit surface, including gradients, variables, and rich-text runs. Keep referenced binary media in <code>assets/</code>; FNX refers to an asset by ID rather than embedding raw bytes.

<Callout type="info">
A design's FNX source is part of its project directory. An isolated FNX file is not the full project: it depends on the manifest, sidecars, shared document data, and referenced assets.
</Callout>
