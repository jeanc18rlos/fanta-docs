title: Export designs
description: Export visuals and, in current source, portable Motion JSON.
---

The signed Public Alpha's visual export controls support PNG, JPG, SVG, and PDF. Add export settings in the inspector, choose a format, and run the export. Raster PNG and JPG presets offer 1x, 2x, and 4x scale. The app writes files into the project's <code>exports/</code> directory. Current, unreleased v2 source also adds Motion JSON and Figma Motion JSON export formats; these are not claimed for the signed Public Alpha.

## What gets exported

If layers are selected, each selected layer is exported separately using its visual bounds. With no selection, Fanta exports the active page. Output names are made safe for filenames, and duplicate selected-layer names receive distinct names.

PNG and JPG are raster images. JPG is encoded as opaque RGB at a fixed quality setting of 95; transparent areas are composited over white. JPG compression can change pixel colors, particularly near sharp transitions. Use PNG when you need transparency or pixel-level comparison, and inspect important JPG exports. SVG and PDF are visual outputs, not editable Fanta project files. To keep working with design layers, retain the [native project](/docs/formats/fant). Canvas comments and editor measurement annotations are review aids; they are excluded from rendered output.

## Motion JSON in current source

The v2 export format list offers **Motion JSON** and **Figma Motion JSON**. A motion export needs exactly one animation clip in its target. Select the frame scoped to that clip, including all of its animated layers, or export the complete clip from **Design → Export Motion JSON**. An empty target, multiple clips, or tracks extending beyond the selected frame produce an error rather than a partial animation.

Motion JSON is Fanta's portable clip specification: it uses seconds and degrees, distinct from the project's `doc/motion.json` storage. Figma Motion JSON maps supported tracks to manual keyframe tracks and includes diagnostics for unsupported properties or transforms. Its node references are Fanta IDs. A Figma plugin or import workflow must map them to matching destination nodes with their resting placement before applying tracks; exporting JSON alone does not animate a Figma file. Physical spring segments are sampled at the clip's frame rate, with a 10,000-sample limit per segment. Keep the editable Fanta project for further authoring. [Motion editor →](/docs/editor/motion)

## Size limits

Raster export is bounded by an 8192-pixel maximum dimension and about 16 million total pixels per output. A large design at 4x may exceed these limits; reduce the scale or export a smaller selection. The export flow reports failures rather than silently writing a partial result.

## Agent screenshots are different

The local MCP <code>get_screenshot</code> tool returns PNG image content to the agent for inspection. It captures the active page by default, or a specified page or node, and defaults to a 768-pixel maximum dimension; the requested maximum is clamped to 16–1568 pixels. It is a review tool, not the inspector's file-export command. Neither the signed Public Alpha's 13 tools nor current source's 14 tools include a separate file export method for PNG, SVG, PDF, Motion JSON, or JSX.
