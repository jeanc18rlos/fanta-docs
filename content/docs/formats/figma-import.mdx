---
title: Import from Figma
description: Open a .fig file and continue editing it as a native Fanta project.
---

Fanta can open a local <code>.fig</code> file and convert it into an editable project. The import path handles Figma document data such as pages, layers, components, instances, auto layout, vectors, effects, and variables where supported by Fanta's document model.

## Open a .fig file

Open the file in the desktop app. On first open, Fanta parses it and materializes a sibling Fanta project directory. You can edit the imported design from that first session. The original <code>.fig</code> remains an import source; the sibling project becomes the working copy.

If you open the same <code>.fig</code> again after a project was created, Fanta redirects to the existing sibling project. This preserves newer edits instead of reimporting the original file over them.

## Check the result

Large imported documents can contain thousands of nodes. Inspect the page tree and key components in the editor, then compare visual output against the source. Some source features may not have an exact editable counterpart, and conversion should be verified for the pages you intend to use.

For agent inspection, <code>batch_get</code> supports depth limits and pagination. Read smaller portions of a large imported page and request detailed nodes by ID. Capture a screenshot of the page or relevant node to review rendering.

Continue work in the Fanta project directory and keep its project files and assets together. Use [visual export](/docs/formats/export) when you need PNG, JPG, SVG, or PDF output.
