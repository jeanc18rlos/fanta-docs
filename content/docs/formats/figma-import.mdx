---

Fantaisa imports Figma `.fig` files through the `fanta-fig-interop` crate. It
reads Figma's **Kiwi** binary format directly and maps it onto Fantaisa's
renderer-agnostic scene graph, so an imported file becomes a first-class,
editable document — not a flattened picture.

## Import a .fig

```json title="open_document with the fig format"
{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"open_document","arguments":{"path":"/work/system.fig","format":"fig"}}}
```

The importer translates at the boundary and preserves the document invariants the
model relies on, so the result behaves like a native Fantaisa document.

## What's covered

The importer maps the high-value Figma domains end-to-end:

| Domain | Notes |
| --- | --- |
| **Components & variants** | Masters, instances, variant sets, instance swap, nested instances |
| **Instance overrides** | Text / fill / visible overrides, component-prop channels |
| **Variables & modes** | Collections, modes, per-mode values, color bindings, per-frame mode pinning |
| **Auto-layout** | Horizontal / vertical, alignment, gap, padding, hug / fixed, child fill / stretch, reverse-z |
| **Vectors** | Vector geometry, fill rule, arcs, stars / polygons, boolean-op results |
| **Effects** | Drop / inner shadow, layer & background blur, all 15 blend modes, masks |
| **Strokes & fills** | Solid / gradient / image paints, stroke align, per-side weights, dashes |
| **Text** | Family / weight / size, alignment, decoration, per-character style runs, auto-resize |

Some properties are partial or deferred by design (for example decorative stroke
caps, image color adjustments, constraints). The authoritative, per-property
status lives in the project's Figma coverage matrix; treat the table above as the
shape of what lands, not an exhaustive contract.

## Fidelity, not approximation

Import correctness is held to a **fidelity oracle**: imported documents are
rendered and diffed against a cross-renderer reference (built from the OpenPencil
Figma schema) so the mapping is validated pixel-for-pixel on a corpus, rather than
trusted by inspection. Where Fantaisa exceeds the oracle — layer masks,
node-level blend modes, per-side stroke bands, richer auto-layout and variable
scoping — those are covered by dedicated unit tests.

<Callout type="info">
  After importing, verify visually with [`export_png {node}`](/docs/formats/export)
  on individual frames before treating the result as final.
</Callout>

## After import

An imported `.fig` is a normal document: edit it live, version it as
[`.fnx`](/docs/formats/fnx), package it as a [`.fant`](/docs/formats/fant), or
[export](/docs/formats/export) it. Reparenting, overrides, and variable bindings
all follow the standard [build rules](/docs/mcp/best-output).
